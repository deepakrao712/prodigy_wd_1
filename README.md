Interactive Web Page with Day/Night Theme Toggle and Smooth Scrolling
Overview
This is an interactive web page featuring a dynamic day/night theme toggle, smooth scrolling, and an elegant, responsive navigation menu. The webpage is designed to showcase different sections: Home, About, Services, and Contact, each with their own unique background images.

The project includes:

Automatic Day/Night Theme Switching: The theme automatically changes based on the time of day, with an option for users to manually toggle between light and dark modes.

Smooth Scrolling Navigation: Clickable links in the navbar smoothly scroll to their corresponding sections on the page.

Responsive Design: The page is fully responsive, ensuring a great user experience across desktops, tablets, and mobile devices.

Active Link Highlighting: As users scroll through the page, the current section is highlighted in the navigation bar.

Features
Day/Night Theme: The page will detect the time of day and automatically switch between light and dark modes. Users can also manually toggle between the two themes using the theme button.

Responsive Layout: The layout adapts seamlessly to different screen sizes. On smaller screens, the navbar changes to a vertical layout, ensuring easy navigation.

Smooth Scroll: Clicking on the navigation links smoothly scrolls to the respective section of the page.

Active Link State: As you scroll through the page, the active section is highlighted in the navbar, indicating which section is currently visible.

Tech Stack
HTML for the structure of the page.

CSS for the styling, including responsive design and smooth scrolling.

JavaScript for the interactive elements, such as theme toggling, scroll behavior, and active link highlighting.

How to Use
Clone or download the repository.

Open index.html in your browser to view the page.

The theme will automatically switch between day and night based on the current time. Click on the moon icon to toggle the theme manually.

Use the navigation bar to jump to the different sections of the page with smooth scrolling.
